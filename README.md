# DeployableKirigami

## Introduction
This repository is intended to document and share the project of deployable Kirigamis developed from the Mecawet group at the PMMH Laboratory of the ESPCI University. 
The deployable kirigamis are a special kind of Kirigami designed primarily to operate in bending mode. Therefore, the cuts in the material are made to form a series of connected ribbons. In this project, we focused in the creation of patterns that deploy into 3D surfaces.

## Installation

No special procedure is required to install; just clone the repository. A requirement file was added to this repository
